# Testing modularOS

The full testing guide comes with the beta invitation. The short version:

1. Start a Claude Code or Codex session and watch the dot appear by the notch.
2. Let an agent ask for permission and answer from the card.
3. Ask Glauka for a prompt and send it to an agent.
4. Tell us what broke or felt wrong.

## Reporting what you find

Open an [issue](https://github.com/klemensgc/modular-os/issues). Say what you did, what you expected and what
happened, and which version you used (the **Version** line in the menu bar icon menu).

Never attach session files, prompts or keys. For a security problem, see [SECURITY.md](SECURITY.md) instead.
